**The World in One Day — Wednesday 18 November 2026**, in a single image.

A newspaper-style front page with four panels, one per story that defined the day:

- **Shenzhen summit** — Xi Jinping and Vladimir Putin met at APEC in Shenzhen, with Donald Trump arrived for a three-way summit the next day: the day's diplomacy ran through China.
- **Drones over the Gulf** — Iran sent drones at US installations in Kuwait, Bahrain intercepted attacks before dawn, US aircraft struck a missile site on Qeshm Island, and tanker traffic through Hormuz sailed on under fire.
- **Cyclone Akvan** — a severe cyclone spiralled toward India's east coast, flooding villages in Odisha and forcing large-scale evacuations.
- **A blue wave in Washington** — Alaska's Senate result (Peltola over Sullivan) handed Democrats a projected 56–44 Senate majority, drawn as a wave breaking over the Capitol with a ballot box in front.

The program (`main.py`, Python standard library only) copies the image it ships (`entry.png`, 1024×1024, under 1 MiB) to the output directory — no network, byte-identical on every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
# writes out/entry.png
```
